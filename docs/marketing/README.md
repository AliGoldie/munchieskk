# MunchiesKK Marketing & SEO

This is the persistent home for marketing/SEO strategy and technical work on
this site, so it survives across sessions instead of living only in chat.

## Scope

- **Technical SEO** — meta tags, structured data, sitemap, canonical URLs,
  page speed, crawlability. Lives in this repo because it's code (`vercel.json`,
  `index.html`, page components).
- **Strategy & campaign ideas** — positioning, content pillars, promo ideas,
  keyword targets. Drafted here, acted on by whoever runs the actual
  socials/ads (currently manual — no posting/ads account access from this
  session).
- **Brand reference** — the existing [MunchiesKK Brand & Menu Brief](https://claude.ai/artifact/AkeQu66bGoe6UeJgXFYBCa)
  doc has the menu, pricing, social links, and brand voice pulled from the
  live site/DB. Treat it as the source of truth for facts; this folder is
  for strategy built on top of those facts.

## Coordination with the content team

A separate session ("CONTENT TEAM LOCAL") works against
`github.com/AliGoldie/content-team` and owns content production
(posts, graphics, status board). This repo/folder owns the site-side
technical SEO and overall marketing strategy. Cross-reference, don't
duplicate — check in before building something the other side already has.
