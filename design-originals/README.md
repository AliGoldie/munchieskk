# Design originals

Source artwork (mascot, game screenshots, platter mock-ups, raw game sprites, the Illustrator file `trex.ai`).

**The website does not use these files.** The images the site actually shows live in `public/images/`, already resized and converted to `.webp`. Edit or replace art here, then export a web version into `public/images/` (see `scripts/make-image-variants.py`).
